This section walks you through setting up Injectify in your Dart or Flutter project, annotating your first classes, and running code generation.

---

## In this section

- [**Installation**](installation/)
  Prerequisites, dependency configurations, and project structure requirements.
- [**Quickstart**](quickstart/)
  A step-by-step tutorial to create a container, annotate dependencies, run `build_runner`, and bootstrap your app.
- [**Monorepo Setup**](monorepo-setup/)
  Best practices for structuring workspace packages, Melos integration, and shared code generation.

---

## Prerequisites

- **Dart SDK**: `^3.12.0` or higher (Flutter SDKs bundled with Dart `3.12+` also work).
- **Package Manager**: standard `pub` or workspace tools (such as `melos`).
